# Big-Market 抽奖平台

Big-Market 是一个基于 Spring Boot 和 DDD 领域驱动设计实现的营销抽奖平台，主要围绕抽奖策略、抽奖活动、奖品发放、用户积分、行为返利等业务场景展开。

项目重点关注高并发抽奖场景下的库存扣减、概率计算、规则编排、异步发奖、幂等控制以及分布式扩展能力。

## 项目特点

- 基于 DDD 领域驱动设计进行业务分层
- 支持抽奖策略装配与 Redis 缓存预热
- 支持概率抽奖、权重规则、黑名单、库存、次数限制等抽奖规则
- 支持活动总次数、日次数、月次数限制
- 支持奖品解锁与保底规则
- 支持积分支付和行为返利
- 支持 RabbitMQ 异步发奖、返利和库存处理
- 支持 Redis 分布式库存扣减
- 支持 Redisson 分布式锁与缓存操作
- 支持 ShardingSphere 多数据源及分库扩展
- 支持 XXL-JOB 定时任务
- 支持 ZooKeeper 动态配置中心
- 支持接口限流
- 支持统一响应结构与全局异常处理
- 提供 JMeter 压测脚本及压测数据生成工具

## 核心业务模块

### 1. 抽奖策略

抽奖策略用于维护奖品、中奖概率以及抽奖规则，主要包含：

- 奖品概率配置
- 奖品库存管理
- 抽奖策略装配
- Redis 概率表预热
- 黑名单规则
- 权重规则
- 保底规则
- 奖品锁定与解锁规则
- 抽奖结果计算

### 2. 抽奖活动

抽奖活动用于管理用户参与抽奖时的活动额度和活动规则，主要包含：

- 活动配置
- 活动 SKU 配置
- 活动库存管理
- 用户总次数限制
- 用户日次数限制
- 用户月次数限制
- 活动参与订单
- 活动抽奖流程
- 活动装配和缓存预热

### 3. 奖品发放

抽奖完成后，通过消息队列异步处理奖品发放：

- 创建用户中奖记录
- 发布发奖事件
- RabbitMQ 异步消费
- 积分类奖品发放
- 奖品发放状态管理
- 发奖任务重试和补偿

### 4. 用户积分

用户积分模块主要用于：

- 用户积分账户管理
- 积分充值
- 积分扣减
- 积分订单
- 积分交易流水
- 积分支付抽奖额度

### 5. 行为返利

行为返利模块支持根据用户行为发放抽奖次数或积分奖励，例如：

- 每日签到
- 行为返利订单
- 返利任务处理
- 返利消息异步消费
- 返利幂等控制

## 项目架构

项目按照 DDD 思想进行模块划分：

```text
Big-Market
├── Big-Market-app              # 应用启动、配置及 Spring Boot 入口
├── Big-Market-domain           # 领域层，核心业务逻辑
├── Big-Market-infrastructure   # 基础设施层，DAO、PO、仓储实现、Redis 等
├── Big-Market-trigger          # 触发器层，HTTP 接口、定时任务、消息监听
├── Big-Market-types            # 公共类型、枚举、异常、响应对象、常量
├── big-market-api              # API 接口定义及 DTO
├── docs                        # 数据库脚本、部署脚本、接口文档
├── perf                        # 压测脚本、造数脚本及压测说明
└── pom.xml                     # Maven 父工程
